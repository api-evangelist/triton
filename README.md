# Triton Inference Server (triton)
NVIDIA Triton Inference Server provides a cloud and edge inferencing solution optimized for both CPUs and GPUs. Triton supports an HTTP/REST and GRPC protocol that allows remote clients to request inferencing for any model being managed by the server.

**URL:** [Visit APIs.json URL](https://github.com/triton-inference-server/server)
